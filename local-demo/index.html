    Seven checks run before a single token moves, and the vault holds an eighth of its own. Each button provokes the real thing against the contracts you just watched being deployed — these are live calls, not recordings.

    Fresh chain, no fork, no network. The page deploys the same contracts the test suite covers, straight from forge's build output. anvil signs the mandate as the principal (eth_signTypedData_v4) and the router computes its own digest, so there is no cryptography and no dependency in this page at all.
